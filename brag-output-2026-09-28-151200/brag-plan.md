# FarmConnect — professional project presentation

## Objective
Explain how FarmConnect connects farm owners with suppliers and administrators through a role-based app for livestock records, supply browsing, requests, inventory and feedback.

## Process shown
Owners maintain livestock records, search medicine and feed listings, select a product and livestock in a request form, and track request status. Suppliers manage inventory, review incoming requests, approve or reject them, and view owner feedback.

## Tools and architecture
Angular 16 with TypeScript, HTML and CSS; ASP.NET Core Web API; Entity Framework Core; SQL Server; JWT authentication and role-protected routes for Owner, Supplier and Admin roles.

## Outcome
A full-stack application that brings the owner and supplier workflows into one role-based system. This presentation describes the repository’s implemented features without claiming deployment, usage metrics or measured business impact.
